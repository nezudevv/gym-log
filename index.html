This page saves each session as an issue in your private repo. It needs an access token once; it's stored only in this browser.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → workout.
  3. Permissions: Repository permissions → Issues: Read and write. Leave everything else as is.
  4. Pick an expiration, tap Generate token, copy it and paste it below.
